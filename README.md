# Mauritius Trip WOW

Static one-page travel timeline for GitHub Pages.

## Publish
Upload `index.html` and `.nojekyll` to the repository root, then:
Settings → Pages → Source: Deploy from a branch → main → /(root) → Save.

The site URL will normally be:
https://YOUR-USERNAME.github.io/REPOSITORY/

## Edit
All itinerary data is inside `const DATA = {...}` near the bottom of `index.html`.
